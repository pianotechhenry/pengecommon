# samples/

Your own files for the desk. Nothing here is written by the tool except reports.

- `baseline.md`: a few passages of your own finished prose (Markdown, blank line between
  paragraphs). If it is present, `desk check` compares each paragraph's Latin/French share
  with these passages instead of reporting the share alone.
- `book2_ch1-2.md`: the Book Two draft used by acceptance test 2
  (`python scripts/acceptance_items.py`). It was not in the repository when the desk was
  built, so that test was run on the listed items alone.

Reports written next to files here (`*.report.html`, `*.report.json`) are ignored by git.
